Starting a new lesson on Duolingo

A close look at the small, bouncy moment between opening the Learn path and jumping into your next lesson: the floating tag, the squishy button, and the popover that pops out underneath.

Original interface

The microinteraction lives on Duolingo's Learn tab, on the lesson path: the winding map of circular lesson buttons connected by little dots.

02

Triggers

The interaction has one system trigger that sets the stage and several user triggers that move it forward.

  1. System

    Landing on the Learn path

    When the path loads, Duolingo finds your next unlocked lesson and places a floating START tag above it. No input is needed; the page itself starts the microinteraction.

  2. Hover in

    Cursor enters the lesson button

    Moving the mouse over the round lesson button changes the cursor to a pointer and pushes the button down slightly.

  3. Hover out

    Cursor leaves the button

    Moving off the button without clicking lets it spring all the way back up to its resting position.

  4. Click / tap

    Pressing the button

    Clicking pushes the button down completely and opens a popover underneath it.

  5. Hover in

    Cursor enters the popover's START button

    Hovering the START button inside the popover changes the color of its text, signaling it is ready to launch the lesson.

03

Rules

1 Only the next lesson gets the spotlight

The floating START tag appears over one button only: the current, unlocked lesson. It keeps bobbing up and down for as long as the user does nothing, and it disappears once that button is pressed and the popover takes over.

2 Button depth follows the cursor

The button has three heights. Resting: fully raised, with its thick bottom edge showing. Hovered: sunk partway. Pressed: sunk all the way (the bottom edge disappears) and the popover opens beneath it with the lesson name, progress and a START button. Leaving before clicking always returns the button to resting.

04

Feedback

See

  • A white START tag gently floating up and down.
  • The cursor turning into a pointer over the button.
  • The button sinking a little on hover and all the way on click, as its darker bottom edge shrinks.
  • A green popover appearing below with the lesson info.
  • The START button's text changing color on hover.

Hear

Nothing. The path map stays silent. Duolingo saves its sound effects for inside the lesson, so the map feels calm and doesn't nag.

Feel

There is no physical vibration on desktop, but the button feels physical. The thick bottom edge collapsing as you press makes it look like a real, squishy button being pushed into the page.

05

Loops & Modes

Loops

  • Idle loop: the START tag bobs up and down forever until the button is pressed.
  • Hover loop: hovering in and out can repeat endlessly; the button sinks and rises every time with no limit.
  • Long loop: after a lesson is finished, the START tag moves to the next node on the path, and the whole microinteraction starts again there.

Modes

  • Locked mode: gray nodes further down the path have no START tag and can't start a lesson yet.
  • Completed mode: finished nodes change color and offer practice instead of a new lesson.
  • Popover-open mode: the START tag is hidden while the popover is open; clicking elsewhere closes it and returns the button to resting.
  • Touch mode: on phones there is no hover, so a tap skips straight to the pressed state.
